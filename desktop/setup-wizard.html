Bienvenue dans Guyma Cyb

Guyma Cyb est un logiciel Windows qui exécute de vrais outils Linux de sécurité (nmap, aircrack-ng, hashcat, searchsploit, metasploit…) grâce au pont WSL (Windows Subsystem for Linux). Inspiré de StrykerOSS sur Android, adapté à Windows.

Cet assistant va configurer

WSL — Windows Subsystem for Linux (les outils Linux y tournent)
Les outils Linux manquants (nmap, aircrack-ng, nikto, hashcat…)
Vérification du noyau Rust (optionnel — fallback Node disponible)
Scans de base (HTTP, ports, DNS, TLS, réseau local) fonctionnent SANS WSL via Node

Vous pouvez configurer plus tard, mais les modules WiFi / Arsenal avancés nécessiteront WSL. Le scan web de base est immédiatement disponible.

Étape 2 — WSL (Windows Subsystem for Linux)

Guyma Cyb vérifie si WSL est déjà installé sur votre machine. Les scans de base (HTTP, ports, DNS, TLS, réseau local) fonctionnent SANS WSL via le moteur Node intégré.

Vérification de WSL… en cours
infoWSL n'est pas installé — voulez-vous l'installer ?

L'installation est proposée, jamais imposée. Cliquez sur le bouton ci-dessus pour lancer l'installation officielle Microsoft (fenêtre UAC — droits administrateur requis, un redémarrage peut être demandé), ou installez-le vous-même via la documentation officielle, puis relancez la vérification.

Guyma Cyb n'installe jamais WSL de lui-même : l'installation n'est lancée que si vous cliquez sur « Installer WSL ».

Étape 3 — Outils Linux de sécurité

Dans WSL, installons les outils de pentest. La détection est réelle (vérifie which dans WSL).

Détection des outils… en cours

L'installation utilise sudo apt-get install dans WSL — votre mot de passe WSL vous sera demandé. Liste : nmap, nikto, whatweb, aircrack-ng, tshark, iperf3, dnsrecon, sslscan, sqlmap, gobuster, hashcat, exploitdb (searchsploit).
